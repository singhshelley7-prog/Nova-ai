# NOVA - AI Productivity Platform

NOVA is a modern SaaS-style landing page for an AI productivity platform.

The idea behind NOVA is to help teams manage projects, organize tasks, automate repetitive work and collaborate from one place.

## Features

- Responsive navigation
- Mobile hamburger menu
- Smooth scrolling
- Hero section
- Trusted By section
- Features section
- Product dashboard
- How It Works section
- Statistics section
- Solutions / Use Cases
- Testimonials
- Pricing plans
- FAQ accordion
- Final CTA section
- Sign In page
- Start Free Trial page

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- React Icons
- JavaScript
- HTML
- CSS
